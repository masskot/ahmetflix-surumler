# ahmetflix — sürümler

ahmetflix'in yayınlanmış sürümleri (Windows).

- **Güncelleme:** Uygulama yeni sürümü buradan kendisi denetler; yeni sürüm çıkınca uyarır ve tek tıklamayla günceller
  (Ayarlar › Hakkında › Güncellemeler). Uygulama buraya kendi sürüm numarası dışında hiçbir bilgi göndermez.
- **Her sürümde:** Windows kurulumu, o sürümün kaynak kodu (`…-kaynak.zip`, GPLv3) ve sürüm bilgisi (`surum.json`:
  dosyanın adresi, boyutu ve SHA-256 özeti).
- **İlk kurulum:** Kurulum imzasız olduğu için SmartScreen "Ek bilgi › Yine de çalıştır" ister. Yeni sürüm eskisinin üstüne
  kurulur; kaldırmak gerekmez, veriler korunur.
- ahmetflix yalnızca bir oynatıcıdır: hiçbir yayın, liste ya da kanal içermez ve önermez. Kullanıcı kendi M3U ya da
  Xtream Codes bilgisini girer.

Lisans: GPLv3 (kaynak arşivindeki `LICENSE`). Üçüncü taraf bileşenler: kaynak arşivindeki `THIRD_PARTY_NOTICES.md`.

---

Published releases of ahmetflix (Windows installer). The app checks this repository for updates and sends nothing but
its own version number. Each release contains the Windows installer, the release's source code (GPLv3) and `surum.json`
(file URL, size, SHA-256). ahmetflix is only a player: it contains and recommends no streams, playlists or channels.
